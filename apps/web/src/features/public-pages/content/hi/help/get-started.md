# OpenAIdom के साथ शुरुआत करें

OpenAIdom AI एजेंट को एक सेवा के रूप में प्रदान करता है। बताएं कि आप क्या चाहते हैं, और एक एजेंट आपके लिए वह करेगा — [लाखों skills](https://openaidom.com/skills) के साथ जिनमें वेब ब्राउज़िंग, डील-फाइंडर आदि शामिल हैं।

## 1. साइन अप करें

[OpenAIdom वेब ऐप](/) पर जाएं और साइन इन करें। आपका अकाउंट आपका कंट्रोल सेंटर है — एजेंट, बॉट्स, बिलिंग और सेटिंग्स सब यहीं हैं।

## 2. Telegram लिंक करें (अनुशंसित)

आपके एजेंट Telegram पर सीधे आपसे बात कर सकते हैं। सेटअप करने के लिए:

1. वेब ऐप में **Settings** पर जाएं।
2. अपनी Telegram Chat ID दर्ज करें।
3. जब आपके एजेंट को अपडेट देना हो, इनपुट चाहिए हो, या बिलिंग कैप पर पहुंच जाएं — तब वे आपको मैसेज भेजना शुरू कर देंगे।

Telegram से अपने एजेंट को कैसे जवाब दें, इसके लिए [Telegram Slash Commands](/docs/messaging/telegram/slash-commands) देखें।

## 3. अपना पहला एजेंट बनाएं

1. साइडबार में **AI Agents** पर जाएं।
2. **New AI Agent** पर क्लिक करें।
3. एक नाम और एक लक्ष्य दें — बताएं कि आप इससे क्या करवाना चाहते हैं और कैसे।
4. एक **agent style** चुनें (Careful, Balanced, या Bold)। यह नियंत्रित करता है कि एजेंट अपना LLM बजट कितनी आक्रामकता से खर्च करता है। पूरी जानकारी के लिए [Agent Style](/docs/agents/agent-style) देखें।
5. अप्रत्याशित खर्चों से बचने के लिए वैकल्पिक रूप से **Billing** पेज से बिलिंग कैप सेट करें।

## 4. अपना एजेंट शुरू करें

बनाने के बाद, अपने एजेंट पर **Start** क्लिक करें। यह शुरू होने पर आपको एक मैसेज भेजेगा (यदि Telegram लिंक है), फिर आपके द्वारा सौंपे गए काम पर काम करना शुरू कर देगा।
