# Bug Report: Unknown routes show React Router dev error page instead of a custom 404

- **Status:** CLOSED
- **Severity:** Low
- **Date:** 2026-06-04
- **Summary:** Navigating to any undefined route (e.g. `/does-not-exist`) shows the React Router default `ErrorBoundary` with the message "Unexpected Application Error! 404 Not Found — Hey developer 👋 You can provide a way better UX than this when your app throws errors by providing your own ErrorBoundary…". This is a developer-facing message that should not be visible to end users.

## Root Cause

`apps/web/src/app/router.tsx` has no `errorElement` defined on the root route or any child routes. React Router falls back to its built-in default error boundary, which is intentionally developer-centric.

## Expected Behaviour

A friendly 404 page with a "Go home" or "Back to Mission Control" link, not a dev-mode error dump.

## Reproduction

1. Log in.
2. Navigate to `http://localhost:8080/does-not-exist`.
3. Observe the React Router default error page.

## Suggested Fix

Add an `errorElement` (or `ErrorBoundary` component) to the root route in `apps/web/src/app/router.tsx`:

```tsx
{
  path: '/',
  element: <RootLayout />,
  errorElement: <NotFoundPage />,   // or a generic error boundary
  children: [ ... ]
}
```

Create a simple `NotFoundPage` component that shows "Page not found" and links back to `/mission-control`.

## Files to Change

- `apps/web/src/app/router.tsx`
- Add `apps/web/src/features/errors/NotFoundPage.tsx` (or equivalent)

## Fix Applied (2026-06-09)

Added a `*` catch-all route as the last child of the root route in `apps/web/src/app/router.tsx`, rendering a new `NotFoundPage` component.

- Created `apps/web/src/app/NotFoundPage.tsx` — renders inside `RootLayout` (sidebar/nav visible), shows `EmptyState` with title "Page not found", message "The page you're looking for doesn't exist or has been moved.", and a "← Back to Mission Control" CTA button.
- Updated `apps/web/src/app/router.tsx` — imported `NotFoundPage`; added `{ path: '*', element: <NotFoundPage /> }` as the last child of the root route.

## Verification

Navigated to `/does-not-exist` in the browser. Previously showed the React Router dev error ("Hey developer 👋"). After fix: shows the branded HeroBids 404 page with full nav sidebar and the "← Back to Mission Control" button, which navigates correctly to `/mission-control`. `pnpm lint` clean.
