The 900 decision log is historical. New decisions go here. 900 links here.

Status values: `approved`, `superseded`, `open` (needs owner decision, do not rely on it), `proposed — pending owner confirmation` (recorded by an implementer, only the owner approves, do not rely on it).

| DEC-50 | Schema note section 7 requires a decision for any new column. CH2W slice 2 added `conversation_messages.queued_at` (timestamptz, not null, default `now()`, migration `0085_redundant_hammerhead`), outside the schema note approved in DEC-47. It records when a row last entered `queued`: equal to `created_at` on insert, restamped by a retry claim. Why: a `queued` row whose process died before publishing must be re-publishable after `messaging.conversations.staleQueuedAfterSeconds` (default 60).
