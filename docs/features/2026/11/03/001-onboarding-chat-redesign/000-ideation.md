We want to improve user onboarding. Right now: 
- new users who click "Try it" on the home/landing page are chatted to with some pre-set messages, they are asked to enter their email via chat
- users receive a login link
- when users return from clicking the login link, they are faced with a form to fillto create an agent, click to review
- click to submit
- wait 30 - 60 seconds for the agent to be created

We want this:
- new users on the home/landing page are chatted to with some pre-set messages, they are asked to enter their email via chat
- users receive a login link
- when users return from clicking the login link, they continue the chat, this time with one pre-set message, followed by real agentic chat. For example:

   - users return
   - agent creation initiated with a chosen name
   - Pre-set message is show after 2 seconds of landing on the page "<agent name> (your own personal agent) is being created, please wait"
   - N seconds later (enough for the user to read the last message) -> we provide some useful information about our platform

   - useful info about platform
   - setup telegram
   - useful info -> "You can start messages on Telegram and continue on the Web, and vice versa."
   - some more useful info
   - hopefully at this point the agent should have been created. We show link to the agents page etc and maybe one or more useful info

   info should always be to the point, without jargon

   The aim is to engage the user while their agent is being created. One of the info we present should be that they can edit their agent (including name) and how/where
